LLM Agent Module

This module integrates AI capabilities into Odoo, focusing on MIS report generation and task management.

The LLM Agent module enables AI-powered automation and task execution within your Odoo environment. It provides specialized AI agents that can handle complex tasks like financial report generation and project management.

Key Features

  • AI Agent Integration for task automation
  • MIS Report Generation with AI assistance
  • Task Automation and management
  • LLM Provider Integration

Prerequisites

System Requirements

  • Odoo 16.0
  • Python >= 3.10.0
  • Valid LLM provider API key (e.g., OpenAI)

Required Python Packages

  • crewai: For AI agent and task management

Required Odoo Modules

  • base: Base Odoo functionalities
  • project: Project and task management
  • llm: Base LLM module for provider integration
  • base_accounting_kit: Required for financial report generation
  • mis_builder: MIS report template creation and management
  • mis_builder_demo: Demo data and examples for MIS reports
Note: Each provider requires appropriate API credentials and configuration. Please refer to the module documentation for setup instructions.

Configuration Steps

1. LLM Provider Setup

  1. Navigate to LLM > Configuration > LLM Providers
  2. Create a new LLM Provider:
    • Name (e.g., "OpenAI")
    • API Key
    • Base URL

2. LLM Model Configuration

  1. Go to LLM > Configuration > LLM Models
  2. Available models will be automatically fetched from configured providers
  3. Enable/disable models as needed

3. AI Agent Setup

  1. Create an internal user with appropriate access rights
  2. Go to LLM > AI Agents and create a new agent:
    • Select the internal user
    • Define Role (e.g., "Financial Analyst")
    • Set Goal
    • Add Backstory
    • Select LLM Provider and Model
    • Enable "Allow Odoo Tools" for MIS report generation

Usage

Setting Up Tasks

  1. Create a Project
  2. Create Task:
    • Assign the AI Agent
    • Provide detailed description
    • Specify expected output
    • Click "Execute AI Task"

MIS Report Generation

When an AI agent has "Allow Odoo Tools" enabled, it can:

  • Create MIS report templates
  • Generate report instances
  • Configure KPIs and styling
Demo & Examples: For detailed examples of AI agent tasks and configurations, please refer to the DEMO.md file in the module directory.

Limitations

  • Limited to specific LLM providers
  • Basic task management features
  • Experimental AI integration
  • Manual configuration required
  • Style options may need adjustment
