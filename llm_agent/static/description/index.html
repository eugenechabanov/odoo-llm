LLM Agent Module

Create and manage AI agents powered by LLM models in Odoo.

The LLM Agent module enables you to create AI agents that can interact with users through Odoo's chat interface. Each agent can be configured with a specific LLM model and system prompt to define its role and behavior.

Key Features

  • Create and manage LLM agents
  • Configure agents with specific LLM models
  • Define custom system prompts
  • Chat with agents in Odoo's interface
  • Real-time message streaming

Agent Management

Each LLM agent includes:

  • Custom name and avatar
  • LLM model selection
  • System prompt configuration
  • Active/inactive status
Note: This module requires the LLM module to be installed and configured with appropriate models.

Installation

Prerequisites:

  • Odoo 16.0 or later
  • LLM module installed and configured

Configuration

After installation:

  1. Go to Settings > LLM Agents
  2. Create a new agent and configure:
    • Name and login
    • LLM model
    • System prompt
  3. Start chatting with your agent in any Odoo chat by mentioning them in message or opening a private chat
Security: Only users with appropriate access rights can create and manage LLM agents.
